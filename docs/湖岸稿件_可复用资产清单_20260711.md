## 四、隐私红线（§11.2 禁止项，目录级指认）

以下内容**不得**复用进 APP 仓库或规则包：

- `10_project_records/` —— 真实出版项目记录（含真实章节标题、项目编号、稿件路径线索）；
- `08_docs/business_plan/` —— 内部商业计划（经营机密）；
- `08_docs/` 其余运维 / 研发过程记录（codex_tasks、upgrade_records、operating_notes 仅可参考工程经验，不复制内容）；
- 仓库 `.gitignore` 声明的受控类别：real_manuscripts、contracts_private、payment_records、identity_documents、font_licenses、production_pdfs 等；
- `07_reports/` 下若存在真实项目报告，须确认已脱敏后方可参考。

`06_samples/`（匿名样本）与 `03_templates/`（模板规格）属可复用资产，不在禁止之列。

## 五、对阶段 0「最小规则集冻结」的输入建议

第一版 20—40 条规则的来源优先级（按 M1 需求排序）：

1. `manuscript_cleaner` 的清理项 → 自动修复白名单候选（连续空格、重复标点、制表符等，正是方案 §5.4 白名单例子）；
2. `word_structure_checker` + `shared/heading_checker.py` → 论文结构与标题层级规则；
3. `footnote_checker` → 注释编号规则；
4. `reference_checker` + `shared/gbt7714_checker.py` → 文内引用对应与 GB/T 7714 结构性检查规则；
5. `shared/chinese_text_checker.py` → 中英文标点与全半角规则；
6. 风格指南（7 份）→ 每条规则的「湖岸解释层」文案来源；
7. `epub_checker` → M3 阶段再提炼，不进第一批清单。
