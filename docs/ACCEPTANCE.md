## 基础版全量验收（方案 §21，阶段 3 前完成）

- [ ] Windows 能安装或解压启动，并完成匿名 DOCX 主流程
- [ ] macOS 能生成可运行包，并在实机完成同一流程
- [ ] DOCX、EPUB、Markdown、TXT 均可导入
- [ ] 不支持或损坏文件显示可理解错误
- [ ] 原稿在全部操作前后 SHA-256 不变
- [ ] 论文、纸质出版物、电子书配置可独立运行
- [ ] 四种引用格式可选择，且不会伪造引用内容
- [ ] 每条问题包含严重程度、解释、位置、标准和修复能力
- [ ] 只有白名单机械问题可自动修复
- [ ] 修复可撤销、可复检且幂等
- [ ] 导出修订稿、EPUB、三种报告和 PDF 样张
- [ ] 脱敏摘要不含正文、标题、文件名、路径和参考文献原文

- [ ] 出版评估入口只出现在结果相关位置

- [ ] 授权到期或网站故障不会锁住本地文件
- [ ] 引用体例「默认」选项按映射表确定性选定，并在报告中说明
