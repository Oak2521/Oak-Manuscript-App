## 功能范围

- 四种输入：DOCX / Markdown / TXT / EPUB；三类检查配置：论文 / 纸质出版物 / 电子书；
- 「默认」引用体例映射 v1.0.0（GB/T 7714—2025 / APA 7 / Chicago 18）；
- 白名单机械修复 6 条（幂等、修复前自动检查点）；
- 导出：修订稿、JSON/MD/HTML 报告、PDF 审阅样张（≤16 页）、基础 EPUB 预览、脱敏评估摘要；
- 外部验证：EpubCheck / Ace（工具可用时真实运行并如实报告；缺失时标注「未运行」）；
- 隐私：全程本地处理，默认网络关闭；原稿只读副本 + SHA-256 全程校验。

## 已知限制

1. **未签名**：Windows SmartScreen 会提示「未知发布者」，内测者需选择「仍要运行」；
2. 无 macOS 构建（需 macOS 环境）；无安装器（仅便携 ZIP）；
3. 湖岸账号 / 同步 / 出版评估提交为占位（网站用户系统上线后接入），入口显示「即将开放」；
4. Ace 可访问性检查需要本机安装 Chrome；EpubCheck 需要 Java 21+；
5. 基础 EPUB 导出已通过 EpubCheck，但尚未内置可访问性元数据（Ace 会如实提示），列入后续改进；
6. 检查记录同步、规则包在线更新、Pro 授权均未启用（阶段 4）。

便携包无安装过程，删除解压目录即完全移除；用户项目目录独立于程序目录，不受影响。
