- **硬约束**：《文脉》期刊受 DOAJ 承诺约束，**永不设登录 / 付费墙**。

**对 APP 项目的含义**：

1. 方案「网站用户系统仍在开发中」的判断**成立**，Provider 占位策略正确；
2. `AuthProvider` 未来的对接目标明确为**网站的 Supabase 认证体系**（支持 OAuth / PKCE 流程，与方案 §11.4 的 PKCE 设想兼容）；
