# 湖岸稿件 功能地图

> 用途：任何一家 AI 都能据此快速找到某个模块的代码与测试，并以"编号"作为协作的锁（issue、分支说明里写 `MS-<编号>`）。
> 粒度：按模块记，不细到每个小功能。改动某个模块的 PR 顺带更新本表对应行。
> 跨模块：一处改动碰到几个模块共用的文件（例如 `electron/main.js`、`electron/preload.js`、`package.json`、`config/tool-manifests/app-resources-v1.json`）时，issue 里登记所有受影响的编号。
> 校验：`tests/feature-map.test.js` 检查表中反引号内的每个路径都真实存在、编号不重复（`npm test` 与 Hosted CI 都会运行）。
