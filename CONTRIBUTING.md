# Contributing to Oak Manuscript

Focused bug reports, tests, documentation, standards research and code contributions are welcome.

The sole collaboration rules are [AGENTS.md](AGENTS.md), especially section 7.
Read them and [AI_HANDOFF.md](AI_HANDOFF.md) before starting. Setup and validation commands
are in [README.md](README.md). This guide intentionally does not duplicate the common rules.

Use a scoped Issue or reference an explicitly approved task, then a dedicated branch and
[PR template](.github/pull_request_template.md). Status and verification are separate:
[DEVELOPMENT_STATUS](docs/DEVELOPMENT_STATUS.md), [TEST_REPORT](docs/TEST_REPORT.md),
[ACCEPTANCE](docs/ACCEPTANCE.md).

Specifications: [commercial plan v2.0](docs/湖岸稿件_Oak_Manuscript_商业正式版开发方案_v2.0_ChatGPT_20260726.md),
[ARCHITECTURE](docs/ARCHITECTURE.md), [SPEC_MODELS](docs/SPEC_MODELS.md), [RULESET_V1](docs/RULESET_V1.md).
For private vulnerability reports follow [SECURITY.md](SECURITY.md).
Tool readiness and local-only work: [collaboration record](docs/COLLABORATION_PREPARATION_20260927.md).
